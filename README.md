# SizzleOS
*(IMPORTANT: THIS IS NOT A FUNCTIONAL OS YET, THIS IS STILL WORK IN PROGRESS)*
A light weight operating system for development,
Upon downloading you will not have any tools or a visual enviroment.

The recommended package manager will be pacman but APT is avalible
Its highly recomended to use KDE plasma as the rendering engine, as it will be the main rendering engine

Installation guide will be provided upon update V1.0
V1.0 will be treated as the offical relese of SizzleOS

Note: If you make any changes to the OS, please don't alter the installation or avoid doing so,
If so please make sure you edit the installation guide, this notice will not be in effect
until V1.0 is released with the installation guide, The OS is planned to be bootable and usable before then
